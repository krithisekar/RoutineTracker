**Daily Routine App**
A simple, serverless web application for creating and viewing daily routines. 
It allows users to create and view their daily routines. The frontend is hosted on Amazon S3, while the backend is powered by AWS Lambda (written in Golang) and AWS DynamoDB for data storage.


**Tech Stack**
Frontend: HTML, CSS, JavaScript
Backend: Go (Golang)
Database: AWS DynamoDB
Hosting & Serverless: AWS S3, AWS Lambda
